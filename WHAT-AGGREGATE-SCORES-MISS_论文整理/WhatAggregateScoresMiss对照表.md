# WHAT-AGGREGATE-SCORES-MISS 对照表

论文：*What Aggregate Scores Miss: Measuring Item-Level Regressions in Commercial LLM API Migrations*（Xiaonan Xu, Wenjing Wu；Georgia Institute of Technology / University of Colorado Boulder；arXiv:2608.17719，2026 年 8 月）

这是一篇测量论文，并没有优化、不修改任何东西。它把商用 API 的模型版本升级当作"依赖升级"来做逐题回归测量：客户端代码与请求参数全部不变，只换 model id，然后用重复采样 + 统计检验判断每道题是可靠改善、可靠退化、实际等价还是不确定。

## 1. 场景与输入

| 子项 | 原文内容 | 原文依据 |
|---|---|---|
| 适配时机 | 事后测量：不做任何适配，只在三条真实的商用升级边（GPT-5.4→GPT-5.5、GPT-5.5→GPT-5.6 Sol、GPT-5.4→GPT-5.6 Sol）上测量升级前后逐题行为变化。 | §3.2 |
| 适用环境 | 900 道单轮、可自动判分的公开基准题：SuperGPQA 500 题（研究生级知识，从全池随机抽）、Omni-MATH hard 100 题（奥数，从 452 题池随机抽）、IFBench 300 个 prompt（指令遵循，全部使用）。3 条边 × 3 基准 = 9 个 migration–benchmark cell。 | §3.3；Table 1 |
| 轨迹来源 | 三个商用模型（API id：gpt-5.4、gpt-5.5、gpt-5.6-sol）直接作答；每题每模型 K=50 次独立单轮调用；无 harness、无工具、无多轮。按发布顺序分阶段采集（先 5.4，再 5.5，再 Sol），阶段内题目×重复顺序随机。 | §3.2；§3.4 |
| 可见轨迹 | 分析只用每条回复的 0/1 判分（主判据 strict）及六类归类（语义正确、语义错误、格式失败、拒答、截断、API 错误）；完整回复级档案（请求参数、原始回复、返回的 model id、usage 元数据、时间戳）已公开发布。 | §3.5；§3.6；Data Availability |
| 交给优化器的输入 | 不适用：没有优化器。分析流程的输入是每题每模型的 K=50 个 0/1 结果，组成 2×K 列联表。 | §3.6 |
| 诊断依据 | 知识与数学题：两阶段解析器从最终答案行提取答案，与参考答案精确匹配后再做符号归一化；IFBench：官方验证器的 strict 与 loose 两种读数（loose 只在固定的表面格式归一化后重跑验证函数，二者仅差格式容忍度）；无 LLM 判官、无人工。 | §3.5 |
| 关注的失败 | 逐题"可靠退化"（correct→incorrect 方向的通过概率可靠下降）；格式失败、拒答、截断计入失败分母（对 API 消费者而言不可解析的回复等同错误）；IFBench 上的 strict 退化中有多少是格式/严格约束遵守问题。 | §3.5；§3.6；§4.3；§5 |
| 禁止使用 | 筛选阶段数据只用于选基准、不进入主分析；题目列表在采集前固定并随档案发布；判分与采集解耦、对档案回复确定性。其他明令禁止项：未说明。 | §3.3；§3.5 |

## 2. 修改对象

| 子项 | 原文内容 | 原文依据 |
|---|---|---|
| 总体 | 不修改任何东西。所有请求参数跨模型保持不变，只有 model id 变化，"模拟客户端代码不变、只有依赖版本变动的升级"。 | §3.2 |
| prompt / 工具描述 | 不修改。知识与数学题使用最小任务陈述 + 最终答案行约定（试点后冻结）；IFBench prompt 逐字使用官方发布版；无工具。 | §3.3 |
| skill / 记忆 | 不修改、不存在：单轮独立调用，无 skill、无记忆。 | §3.2 |
| 控制逻辑（执行前） | 不修改：reasoning effort 对所有模型固定为 medium（三模型共有的档位）；temperature 不被这些模型接受；不设输出长度上限。 | §3.2 |
| 控制逻辑（执行后） | 不修改模型侧任何东西；唯一的"执行后"处理是采集时对瞬时 API 错误指数退避重试直至成功，以及离线的确定性判分。 | §3.4；§3.5 |
| 明确不改 | 模型本身由厂商控制（研究对象正是厂商替换模型带来的变化）；客户端代码、请求参数、prompt、题目列表均不改。 | §3.2；§3.3 |
| 对照组 | 升级边的源模型（5.4 或 5.5）作为目标模型的对照；置换零假设（把每题两模型共 2K 个结果随机重贴版本标签、每侧 K 个，重跑整套分类流程 1,000 次）作为"零真实变化"的校准基线；App. B 的单次抽样比较作为传统做法的对照。 | §3.2；§3.6；App. B |

## 4. 成功标准

| 子项 | 原文内容 | 原文依据 |
|---|---|---|
| 原失败是否修好 | 不适用（无修复）。对应的测量是每条边每基准的聚合变化 Δ（strict 准确率均值差，pp）与可靠改善份额 P+：5.4→5.5：SuperGPQA +2.3 / P+ 8.2%，Omni-MATH hard +7.3 / 17.0%，IFBench +1.9 / 11.3%；5.5→Sol：+1.4 / 7.6%，−4.1 / 9.0%，−3.9 / 6.7%；5.4→Sol：+3.8 / 10.8%，+3.2 / 10.0%，−2.0 / 10.7%。三模型 strict 均值：SuperGPQA 63.4 / 65.7 / 67.1，Omni-MATH hard 45.7 / 53.0 / 48.9，IFBench 62.8 / 64.6 / 60.7。 | §4.1；Table 1 |
| 对其他任务是否有效 | 不适用（无优化，无 held-out）。跨基准差异：5.5→Sol 边上 SuperGPQA 继续上升（+1.4）而 Omni-MATH hard（−4.1）与 IFBench（−3.9）下降。 | §4.1 |
| 回归：流程层面 | 全文主题即逐题回归检测流程：每题 Fisher 精确检验（2×K 表）+ 每个 cell 内 Benjamini–Hochberg FDR 5% + 实际显著阈值 \|p̂_t − p̂_s\| ≥ ε=0.2 → 可靠改善/可靠退化；差值 95% 置信区间完全落在 (−ε, ε) 内 → 实际等价；其余 → 不确定；再与置换零假设的 95 分位比较。 | §3.6 |
| 回归：结果层面 | 9 个 cell 全部同时存在可靠改善与可靠退化。P−：5.4→5.5 为 5.0 / 6.0 / 8.3%；5.5→Sol 为 4.4 / 15.0 / 13.3%；5.4→Sol 为 4.8 / 5.0 / 13.3%（顺序 SuperGPQA / Omni-MATH hard / IFBench）。P_chg 范围 12.0–24.0%；Equiv. 54.3–80.4%；Incon. 7.6–24.7%；Null95 全部为 0.0%。聚合上升的 6 个 cell 中仍有 4.4–8.3% 题可靠退化。重复 K=50；检验见上。 | Table 1；§4.1；§4.2；§5 |

## 5. 迁移范围

| 子项 | 原文内容 | 原文依据 |
|---|---|---|
| 换模型 | 研究对象本身：同厂商同产品线的三条升级边（5.4→5.5、5.5→Sol、5.4→Sol）。直接边 5.4→Sol 的可靠变化份额不等于两条连续边之和，"逐题变化在连续升级间相互抵消"。跨厂商：未测（作者自认）。 | §3.2；§4.1；§6 |

| 换执行环境 | 不适用 / 未测：只有单轮 API 调用，无执行环境。 | §3.2 |

| 补充 | 作者自认三项限制：基准经"有 headroom"筛选，份额是信息性基准上的估计而非任意负载的总体率；只覆盖一个厂商产品线与三个公开基准；ε=0.2 与 K=50 共同决定可检出的变化幅度，更小的真实变化落在"不确定"类。 | §6 |
